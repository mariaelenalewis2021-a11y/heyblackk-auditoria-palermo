# Hey Blackk · Auditoría Palermo

App web instalable (Android y iPhone) para auditar la sucursal Palermo.

- **Instalar en el celular:** abrir el link de la app → Android: menú ⋮ → *Instalar app* / *Agregar a pantalla principal*. iPhone (Safari): botón Compartir → *Agregar a inicio*.
- **Datos:** una única planilla de Google en la cuenta de Hey Blackk (ver `INSTALAR-servidor.md` y `servidor-Code.gs`).
- **Acceso:** clave de auditor (cargar) y clave de jefes (Registro, KPI, Ajustes). Las claves no están en este repositorio.
